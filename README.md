# Aplikasi Produk Toko - JavaFX

Aplikasi desktop sederhana untuk pencatatan dan pengelolaan daftar produk toko yang dibangun menggunakan **Apache NetBeans (JavaFX)**, dan **SceneBuilder**.

## Fitur
- Input Nama Produk, Kategori (Makanan/Minuman), dan Harga Produk (Rp)
- Form penginputan data produk baru dengan validasi input
- Tabel daftar produk interaktif dengan kolom Kode, Nama, Kategori, dan Harga
- Fitur pencarian produk berdasarkan nama produk melalui tombol Cari
- Fitur filter produk berdasarkan kategori (Makanan / Minuman)
- Tombol Lihat Detail untuk melihat rincian informasi produk yang dipilih
- Fitur hapus data produk dari daftar

## Teknologi yang Digunakan
- **Apache NetBeans (JavaFX)**
- **SceneBuilder**

## Demo aplikasi

1. Buka Aplikasi
- Jalankan aplikasi Pencatatan Produk Toko di perangkat Anda.

2. Masukkan Nama Produk

- Ketikkan nama produk pada kolom Nama Produk (Contoh: Nasi Goreng / Es Teh).

- Ketentuan: Nama produk tidak boleh kosong.

3. Pilih Kategori Produk

- Pilih kategori produk pada menu dropdown (Makanan atau Minuman).

4. Masukkan Harga Produk

- Ketikkan nominal harga pada kolom Harga Produk.

- Satuan: Gunakan nominal angka rupiah (Contoh: 15000), nilai harga harus lebih dari nol.
